# Common infrastructure

All common packages now live in the repository-root `shared/` Go module: `contract`, `logx`, `apitoken`, `bundlepair`, `pairing`, `session`, `desktop`, `fsx`, and `webui`. The latter embeds shared static assets, fonts, licenses and templates; application-specific UI stays in each application. See the root `MEBOORU.md` for the active roadmap and acceptance evidence.
